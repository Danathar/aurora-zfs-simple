```bash
for n in $(gh pr list --repo Danathar/aurora-zfs-simple --state merged --limit 500 --json number \
             --jq '.[] | select(.number <= 246) | .number'); do
  inline=$(gh api "repos/Danathar/aurora-zfs-simple/pulls/$n/comments?per_page=100" \
    --jq '[.[] | select(.user.login | contains("codex"))] | length')
  body=$(gh api "repos/Danathar/aurora-zfs-simple/pulls/$n/reviews?per_page=100" \
    --jq '[.[] | select(.user.login | contains("codex")) | .body | scan("P[0-3] Badge")] | length')
  echo "#$n inline=$inline body=$body"
done
```

The findings come from `chatgpt-codex-connector[bot]`. `docs/metrics.md`'s
one-PR command counts only inline comments; this loop also counts findings
posted inside a review body, since every Codex finding carries a `P0`–`P3`
badge wherever it is posted. None of the review bodies carried one, so the
inline count is the total. The count says where review pushed back, not whether
it was right: `AGENTS.md` asks for each finding to be checked before it is
acted on.
